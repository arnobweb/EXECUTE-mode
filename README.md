# Execute Mode

A lightweight execution-continuity skill for complex work and non-linear thinking.

## The idea

Complex work is not always linear.

A question during execution can lead to a useful branch of thinking. The problem is not necessarily the branch itself. The problem is losing the original execution thread, forgetting unresolved items, or never returning to where the work stopped.

## Who might find this useful?

Execute Mode is not an ADHD-specific tool. It is a general interaction pattern for maintaining execution continuity during complex work.

It may be particularly useful for people who experience:

- non-linear or branching thinking
- frequent context switching
- working-memory overload
- difficulty returning to the original task after exploring a side question
- ADHD-related or other neurodivergent executive-function challenges

The goal is not to suppress divergent thinking. It is to make the current branch visible and preserve the path back to execution.

Execute Mode keeps the main execution thread visible while allowing useful exploration.

> Reduce presentation complexity, never reasoning complexity.

## How it works

### EXECUTE
The main work thread stays visible and actionable.

### THINK ↗
When deeper exploration is useful, the branch is explicitly identified rather than suppressed.

When resolved:

**THINK ✓ → ↙ RETURN TO EXECUTE**

The conclusion is captured and execution resumes from the exact point where it stopped.

### NOTICE
Relevant lateral ideas can be acknowledged without turning them into new tasks.

### PARKED
Necessary deferred items are kept only when they have a specific trigger for returning.

No endless "read later" list.

## State recovery

At any point, ask:

`Where are we?`

The assistant returns:

- DONE
- CURRENT
- OPEN THINK
- PARKED
- NEXT

## When to use it

Execute Mode is intended for operational, multi-step work such as:

- coding and debugging
- data work
- complex software tasks
- administrative processes
- project implementation
- any workflow where useful side-thinking can make the main thread disappear

It is not intended to replace open exploration, brainstorming, strategic thinking, creative work, or deep analysis.
